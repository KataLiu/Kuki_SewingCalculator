# Kuki Calculator · 本地试样原型 v0.3

宠物无袖背心量体计算、可调纸样预览，以及实际尺寸 A4 PDF / SVG 导出。无需安装依赖或连接服务，未配置自动发布。

## v0.3 界面与打印更新

- 网页按「量体 → 看纸样 → 下载打印」分步显示，输入跨步骤保留。
- 首页只显示核心三围和结果；松量、公式、教程和微调参数按需展开。
- 纸样页内部只保留裁剪线、对折线及可选净版／辅助线；说明集中在第一页。
- 第一页包含50 mm校准方框、拼接地图、图例和采用尺寸。
- 相邻分页的10 mm重叠区包含同一世界坐标的十字，支持上下及左右拼接。
- 自定义导出可关闭净版线，或添加辅助线。PDF纸样内部始终没有文字。
- 尺寸公式和纸样几何规则未因界面改版而变动。

## 半片与整片选择

「看纸样」和「下载打印」两步都可以选择纸样形式，选择保持同步。

- **半片 · 对折裁**：保留原有半片版，前后片各对折裁一片，中心点划线放在布料对折边。
- **整片展开 · 单层裁**：将半片沿中心轴严格镜像，前后片各在单层布上裁一片。中心箭头仅指布纹方向，不要沿中心裁开，没有中心缝份。
- 预览、A4分页、首页说明、拼接地图、SVG和尺寸笔记均跟随选择。PDF和SVG的下载文件名包含 half 或 full。
- 尺寸表仍列半片公式定位尺寸；整片是其对称展开，长度不变，整体面积加倍。
- 示例半片为5页A4，整片为9页A4；两种均为实际尺寸，不能使用适应页面缩放。

## 打开与使用

在 Chrome 打开 `index.html` 即可使用。也可在项目终端运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8765 。

1. 输入贴皮颈围、胸围、背长；松量与背长减短量分别设置。
2. 点击「看纸样」，调整肩宽、相对竖线的肩角、袖笼曲线、腰围和腹部长度。
3. 检查前后肩线和两侧拼接边长度，以及领口曲线展开长度。
4. 下载 A4 PDF。100%／实际大小打印，先量首张 50×50 mm 校准方框。
5. 每片独立拼页；按照首页地图 B1、B2（后片）及 F1、F2（前片）拼接。有上方或左侧邻页时，沿外框裁去下一张的上／左外边距，再重叠 10 mm，对齐共享十字及纸样线后粘贴。
6. 黑实线是裁剪线，紫虚线是净版轮廓；对折／布纹线不加缝份。前后片各对折裁一片。
7. 先制作试样，核对穿脱、腿部活动、腹部长度与实际缝合情况。

默认是视频示例：实测颈围23、胸围38、背长27 cm；整圈颈胸各加2、背长减2后为25／40／25 cm。不是 Cookie 的实际数据。

## 已实现的规则

- 后胸半片＝胸围×3/5÷2，前胸半片＝胸围×2/5÷2。
- 后领宽＝颈围÷4，后领深＝颈围÷8。
- 前领宽＝颈围÷5，前领深＝颈围÷20（按用户提供截图，未采用文字摘要的÷12）。
- 前胸长＝调整后背长×2/5＋1～2 cm。
- 前胸宽估算＝调整后胸围÷10－0.5～1 cm。
- 后片中心线五等分；肩宽前后等长，相对竖线默认后40°、前60°，向外向下。
- 肩部、两侧拼接边按缝份值外放；两个中心对折边不外放。
- 领口、袖笼默认毛边包条包边，不额外外放。包边条另裁。
- 下摆可选包条包边（不外放）或向内折边（预留折进去的总量）。
- 预览两片使用统一缩放。PDF 使用毫米坐标转换至72/25.4 points，包含校准页、分页编号、拼接重叠区和关键点。
- 无效输入、交叉轮廓、不可用肩点等会暂停导出；最多64张纸样分页，超过范围会提示。

## 必须验证的原型假设

本软件尚未经过真实宠物试穿或专业打版验证。它不是教程的逐点准确复刻。

- 领口、袖笼、下摆采用程序补充的三次曲线，按32段折线采样后生成可变边缘外放。
- 后片两侧拼接终点设在调整后背长3/5＋1 cm；前片对应拼接边按其长度求解。
- 腰线使用直线侧边近似。未填腰围时默认后片收0.5 cm、前片收其2/3；填写腰围后，以腰围＋胸围松量按3:2分配后前片宽度。
- 腹部长度自前胸围线量到前中心下摆；留空默认调整后背长×0.35。未把未验证的公母位置自动写死。
- 实测两前腿间距按整宽输入，除2映射为前片辅助宽；这一映射需试样核对。
- 领口展开弧长与目标颈围可能不同；页面显示差值，不能据此保证领围合身。
- 袖笼曲线调整不保证单调增减袖笼长度；用户应观察图形和弧长。
- 无袖山、袖片、开口搭门，也不自动生成包边条。前后片可能无法套头穿脱，须结合面料、头围及试样验证。
- 曲线折边的吃势和角部处理仍需手工修整。没有自动生成折边转角反折样。
- PDF 说明集中在首页，使用英文以确保不依赖额外字体；纸样框内没有文字，仅框外保留页号与纸张顺序。界面提供中文解释。

## 文件

- `index.html`：量体表、绘图工作台及打版小抄。
- `style.css`：雾紫配色及布局。
- `calculator.js`：尺寸公式。
- `pattern.js`：毫米坐标纸样、曲线、边缘外放与交叉检查。
- `pattern-pdf.js`：纯浏览器矢量 A4 PDF 输出与分页。
- `app.js`：输入、预览、检查、PDF／SVG／笔记导出。

## 验证

```sh
node tests/pattern.test.cjs
```

测试涵盖示例公式、角度基准、前后边长、对折边、边缘余量、参数联动、不可用输入、轮廓交叉及 PDF 分页覆盖。物理打印仍须先用尺验证校准方框。

## 重合线修正

对折边只显示一条点划线；裁剪轮廓不再重复绘制对折边。净版虚线仅在与裁剪边因缝份／折边量分离的位置显示。领口、袖笼等无额外余量的边只显示裁剪实线。PDF、屏幕预览和SVG均采用同一套线型规则，纸样几何及实际尺寸没有变化。
